  1. **Model** (against `844a971`): `mk_b_m L t w room` returns the state, the definition and the
     cost charged: `extra = bcost BinOp_Mul w * (length fs - 2)` (`bcost(4, w)` in Rust), flattening
     only if `ok ∧ 2 < length fs ∧ 0 < w ∧ extra ≤ room`. `norm_loop_b f ws dw` keeps
     `((L, M), seen, spent)`: `seen += ccount ws dw d` before the step,
     `room = (f - 1) * seen - spent` (nat subtraction = Rust's `if spent < lim … else 0`),
     `spent += c`. `normalize_b_m f q`. Differences, stated in the theory text: the counters are
     unbounded naturals (Rust saturates at 2^63; irrelevant below 2^56, as `fb_hyps` requires); with
     no substitution in the model, `seen` grows on every definition (Rust skips the substituted
     ones, which are `Var`s of `ccount` 0).
  2. **Equivalence** `normalize_b_correct` (same statement as `normalize_d_correct`, any `f`).
     `mk_b_ok` gets the flattening arm from `mk_tail_ok` and the other from `mk_raw_ok`. Neither arm
     is proved again. `ninv_step_of` is `ninv_d_step` with the facts of `mk_d_ok` as hypotheses.
     The proof had to be copied because `ninv_d_step` is stated for `mk_d_m`, and the issue says not
     to edit `QFBV_Distrib`.
  3. **Growth** `normalize_b_ccount`: `pcount (normalize_b_m f q) ≤ f * pcount q` for
     `1 ≤ f`, where `pcount p` is the `ccount` sum of `fb_hyps` (defs @ asserts, widths of `p`).
     The loop invariant `norm_loop_b_ok` is `ninv`, `seen = Σ ccount (old defs so far)`,
     `ccs L ≤ seen + spent`, `spent ≤ (f - 1) * seen` and
     `19 * |new defs| ≤ 19 * |old defs so far| + spent`. Per step (`mk_b_ok`):
     `ccs L' ≤ ccs L + ccount t + c`, from `rewrite_cost` / `distribute_cost` (rewrites and
     `distribute` never increase `ccount`, since `15w ≤ 19w²`), `mk_raw_cost` and `mul_fold_cost`
     (each chain product costs `bcost BinOp_Mul w`).
  4. **Definition count** (cheap, so included) `normalize_b_defs_length`:
     `19 * |defs q'| ≤ 19 * |defs q| + (f - 1) * Σ ccount (defs q)`.

## Lessons

- `QFBV_Bound` and `QFBV_Norm` both define `mul_step`. A theory that imports both must write
  `QFBV_Norm.mul_step`.
- A `that` inside `obtain … using that` names the obtain's own premise, not the enclosing
  `if … for` premises. Name those (`if h: …`).
- `metis in_set_conv_nth` and `metis map_cong` hung (the batch build ran past 10 minutes).
  `in_set_conv_nth[of u xs]` with `blast`, and `map_eq_conv` with `arg_cong[where f = sum_list]`,
  are instant.
- `simp` with a conjunction `seen = X ∧ … ∧ P seen` as a premise substitutes `seen` in the goal but
  not in `P seen`, and then fails. Split with `blast+`, or `unfolding … by blast`.
