## Decisions

- Hypotheses: the issue's `length lbd = length db - m0` and `length pos = 2 * length db` are not needed
  for any of the equalities (HOL's `nth` is total); they are only needed by the contract for safe
  indexing, which follows from them directly (`c - m0 < length lbd` for `m0 ≤ c < m`).
- Counting is done with `length (filter … [a..<b])` rather than `card` of sets: the loops step
  along `upt`, so `upt_conv_Cons`/`upt_Suc_append` make each step a one-line `simp`.
- Unfolding a loop one step: `(subst X.simps) (simp only: if_P[OF …] if_not_P[OF …] Let_def …)`; plain
  `simp` with the case hypothesis failed repeatedly on nested `if`s.
