## Patterns

- Two-phase loop proofs: `crush_base` with only cheap rules (definitions of the models, `push_not_None`,
  `word_less_nat_alt`), then `simp_all` with `unat_word_Suc_simp`/`unat_Suc_len` and the model
  step lemmas. `antisym_conv` and `unat_word_Suc_simp` inside `crush_base` (or `simp_all`) make it
  run for minutes.
- A `push` right after `rvec_new` leaves goals with a schematic `?s` for the pushed vector:
  `prefer 3 apply (rule option.collapse[symmetric])`, then `simp_all add: push_not_None`.
- `i mod W = 0` is rewritten by crush; give `rot_mod0` (`(i mod W = 0) = (unat i mod unat W = 0)`)
  to `crush_base`, else the branch condition can end up as `W dvd i` (word `dvd`, not usable).
- Never give simp both `x - 1 = word_of_nat (unat x - 1)` and the default simp set: it splits
  `word_of_nat (a - b)` back and loops.
- For experiments on theories above `QFBV_Refine`: `isabelle-devcopy`, then replace the proofs of
  `dev/QFBV_Refine.thy` by `sorry` (a small script on the top-level `lemma` blocks); the Pool
  Server otherwise runs out of memory loading the full `QFBV_Refine`.
