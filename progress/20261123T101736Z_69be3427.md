## The subset version

How each construct of the prototype that is not in the subset was replaced:

- `HashMap<String, usize>` keyed by `format!`: hash buckets as in the watch lists. `head` has
  `2 * defs + 1` buckets and `next` one entry per new definition; each list ends in `usize::MAX`,
  and `next[k] < k`. The hash `term_hash` is computed in `usize` modulo the prime `2^31 - 1`
  (`mix(h, x) = (31 h + x mod P) mod P`, so nothing overflows). A definition is shared only if it
  is equal (`norm_eq`, with the width), so the hash affects only speed, not correctness.
  A linear search was not an option: pspace has tens of thousands of definitions.
- `struct Norm`: dropped. `defs`, `widths`, `head` and `next` are passed and returned as a tuple,
  as `wpropagate` does.
- `Vec<Option<(usize, usize)>>` of the substitution: two `Vec<usize>` (`sb`: the definition `t`,
  `ss`: the definition `Var(v)` of the assertion) with the sentinel `usize::MAX`. `not_of` returns
  `usize::MAX` for "none" instead of an `Option`.
- `iter().all`, `map().collect()`, `for`, closures, `matches!`, `if let`, `&mut Vec` arguments, the
  `(a, b)` tuple patterns: `while` loops, nested `match` and owned values passed in and out
  (`factors` returns `(Vec<usize>, bool)`). `fs.sort()` became an insertion sort `sort_usize`, and
  `==` on `Vec<bool>` became `same_bits`.
- One fix: the prototype's `x + ~x` test compares `not_of(b) == Some(okey(a))`. With sentinels,
  both sides could be `usize::MAX`, so the test now also requires `a` (resp. `b`) to be a
  reference. `x * ones` also requires `w > 0`, because `cneg` builds `cone(w)`, which needs
  `w >= 1`.
- The section sits after `reconstruct`, below `read_model`.

## Verification plan

Contract of `normalize q` (pure model `normalize_m`): if `cproblem_wt q`, then for `q' =
normalize_m q`:

1. `CoreProblem_widths q' = CoreProblem_widths q` (so `cvar_widths` and `cis_assignment` are the
   same) and `cproblem_wt q'`.
2. For every assignment `m`: `cis_model q' m ⟷ cis_model q m`. No reconstruction is needed:
   `solve` keeps passing the (normalized) `q` to `reconstruct`, and a model of `q` is a model of
   the lowered problem.
3. The bounds that `elim_facts` and the core solver need: `fb_hyps q'` and a bound on
   `csize_bound q'` from those of `q`. This is the one part that is not a pure equivalence. The
   product flattening adds at most 15 new definitions per input definition (cap 16), and
   `x * ones` puts a `cneg` term (`tbound` constant) in place of a product. So either the lowered
   bound (`lower_fb_hyps`, `QFBV_Proof.thy`) has a factor of 16 of slack, or `size_ok` must be
   tightened (it is in `core/`, not `spec/`). Check this first.

Proof of 2, by induction on the index `j` of the old definitions, with `map` the new index of
each. Let σ satisfy the new (resp. old) assertions. Claim: `dv'[map[j]] = dv[j]` (values under
σ via `cdef_values`) and `ds'[map[j]] = ds[j]` (widths).

- A rebuilt definition: `remap` commutes with `ceval` given the claim below `j`. Then each rewrite
  preserves the value:
  - `x = x` → 1 (`cbin_sem BinOp_Eq`).
  - `x + ~x` → ones (`bits_nat_bnot_add`).
  - `x * ones` → `cneg` (`(x * (2^w - 1)) mod 2^w = (2^w - x) mod 2^w`, with the value of `cneg`
    that the proof of `lower_problem`'s `bvneg` case gives).
  - The operand swap (if kept) and the flattening: commutativity and associativity of `*` mod
    `2^w`, with all factors of width `w`. `factors` needs a lemma that the product of the listed
    factors equals the definition's value.
  - Sharing: `norm_eq d t` ⟹ equal `ceval` (commutativity for the swapped case).
- A substituted occurrence `Var(v)` at `j > sb[v]`, `j ≠ ss[v]`: the assertion `a = Ref k`, `defs
  ! k = Eq (Ref s) (Ref b)`, is kept, and in the new problem it is `Eq (Ref map[s]) (Ref map[b])`,
  where `map[s]` is a `Var(v)` definition. That definition is either rewritten to the constant 1,
  in which case `map[s] = map[b]` and both are `Var(v)`, or still an equality. In both cases σ
  satisfying the new assertions gives `σ(v) = dv'[map[b]]`, which equals `dv[b]` by the IH as
  `b < j`. For the old direction, the old assertion gives `σ(v) = dv[b]` directly. The order
  condition `sb[v] < j` is what makes the induction well-founded. There is no circularity: the
  fact used is the assertion's truth in σ, not its rewritten form.
- Then each assertion `Ref k` becomes `Ref map[k]` with the same value.

Reusable: `QFBV_Core.thy` (`cwidth`, `cwt`, `ceval`, `cdef_values`, `cproblem_wt`, `cis_model`),
`QFBV_Eval.thy` (`eval_m_correct`, `eval_defs_m_correct`, `bits_nat_bnot_add`, `bits_nat_badd`,
`bmul_m`), and from the elimination (#51–#54, `QFBV_ElimSpec.thy`, `QFBV_Elim.thy`): the term-walk
contracts `copy_term`, `copy_op`, `ref_index`, `term_width` (`term_width_rec_spec`), `count_occ`
(as the model for the recursive `remap`/`term_eq`/`term_hash` contracts), `cidx`/`cwt_cidx` for
index bounds, and `fb_hyps`/`fuel_bound` for item 3. The `head`/`next` buckets are the watch-list
shape; only "`next[k] < k` or `MAX`" and "`head[h] < length defs` or `MAX`" are needed, for
termination of `find_def` and for its bounds.

Termination and overflow: `term_hash` is bounded by `P`. `factors` recurses on smaller indices
(`x, y < k`) and stops at 16. `find_def` walks a chain with `next[k] < k`. `sort_usize` is
quadratic on at most 17 elements. `remap`, `term_eq`, `norm_eq` and `term_hash` are structural.
The fuel of the translation must cover these recursions, as for `elim`.
